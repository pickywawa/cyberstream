あなたのテレビを、すべて。

ひとつの Rust エンジンで。

Cyberstream は、あなたの Xtream と M3U ソースを再生します。ライブチャンネル、番組表、映画、シリーズ、見逃し配信に対応。同じ WebAssembly モジュールがスマートフォン、テレビ、パソコン、ブラウザで動きます。

デモソースと TMDB のメタデータで録画。

// 01 — 機能

リモコンのために設計し、
スマホでも快適に。

Xtream & M3U

カタログの分割読み込み、バックアップサーバー、差分同期。変更された行だけを書き換えます。

XMLTV 番組表

チャンネル × 時間の仮想化グリッド、日ごとの移動、gzip とタイムゾーンに対応。過去の番組は見逃し配信で再生できます。

映画とシリーズ

TMDB で充実したページ：キャスト、コレクション、年齢区分、シーズンとエピソード、続きから再生、次のエピソード。

ライブ一時停止

30〜60 分のローカルバッファ：HLS ストリームで一時停止、±10 秒、ライブに戻る。バックアップストリームへの自動切り替えも。

音声コマンド

「5 チャンネルにして」「デューンを検索」「30 秒戻して」。端末上で認識し、インターフェースの 14 言語に対応。

QR コードで設定

テレビのコードをスマホで読み取るだけ。リモコンで URL を入力しなくても、プロフィール、ソース、設定が届きます。

無料の見逃し配信

ARTE、france.tv、Okoo を内蔵し、YouTube の RSS フィードにも対応。公共放送は公式ストリームを優先します。

字幕と Trakt

SRT、WebVTT、OpenSubtitles のハッシュ検索。Trakt のスクロブル、ウォッチリスト、ホームでのおすすめ。

プロフィールと金庫

言語、アバター、年齢制限を個別に持つ複数のプロフィール。サービスのトークンは端末の安全な保管領域に残ります。

// 04 — インストール

2 分で準備完了。

  1. 最新リリースから Cyberstream-x.y.z.apk をダウンロードします。
  2. スマホにインストールするか、adb でテレビにインストールします：
adb -d install -r Cyberstream-1.0.1.apk

Android 7（API 24）以上で、WebAssembly に対応した WebView が必要です。その後は、アプリが自動で GitHub の新しいバージョンを確認します。

WebAssembly ターゲット付きの安定版 Rust、Node.js 22.12 以降、npm。

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

開発中は、設定時にデモソースを選べば契約なしで試せます。

デスクトップ版は Electron を使います。ローカルで実行するか、macOS、Windows、Linux のパッケージをビルドします：

npm run desktop
npm run desktop:dist

ソースをつないで、再生するだけ。
