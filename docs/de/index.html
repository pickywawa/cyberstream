// 01 — funktionen

Gemacht für die Fernbedienung,
zu Hause auf dem Smartphone.

Xtream & M3U

Kataloge blockweise gelesen, Ausweichserver, differenzielle Synchronisierung: Nur geänderte Zeilen werden neu geschrieben.

XMLTV-Guide

Virtualisiertes Raster Sender × Uhrzeit, Navigation Tag für Tag, gzip und Zeitzonen inklusive. Vergangene Sendungen laufen als Wiederholung.

Filme & Serien

Mit TMDB angereicherte Seiten: Besetzung, Sammlungen, Altersfreigaben, Staffeln und Folgen, Fortsetzen und nächste Folge.

Live-Pause

Lokaler Puffer von 30 bis 60 Min.: Pause, ±10 s und zurück zu live bei HLS-Streams, mit automatischem Wechsel auf einen Ersatzstream.

Sprachbefehle

„Schalte auf Sender 5“, „suche Dune“, „30 Sekunden zurück“. Auf dem Gerät erkannt, in den 14 Sprachen der Oberfläche.

Einrichtung per QR-Code

Scanne den Code auf dem Fernseher mit dem Smartphone: Profil, Quellen und Einstellungen kommen an, ohne eine URL mit der Fernbedienung zu tippen.

Kostenlose Mediatheken

ARTE, france.tv und Okoo integriert, dazu YouTube-RSS-Feeds. Bei öffentlich-rechtlichen Sendern kommen offizielle Streams zuerst.

Untertitel & Trakt

SRT, WebVTT und OpenSubtitles-Hash-Suche. Trakt-Scrobbling, Merkliste und Empfehlungen auf der Startseite.

Profile & Tresor

Mehrere Profile mit eigener Sprache, eigenem Avatar und eigener Altersgrenze. Dienst-Tokens bleiben im sicheren Speicher des Geräts.

// 04 — installation

In zwei Minuten bereit.

  1. Lade Cyberstream-x.y.z.apk aus dem neuesten Release herunter.
  2. Installiere es auf dem Smartphone oder mit adb auf dem Fernseher:
adb -d install -r Cyberstream-1.0.1.apk

Mindestens Android 7 (API 24) mit einem WebView, das WebAssembly unterstützt. Danach sucht die App selbst auf GitHub nach neuen Versionen.

Stabiles Rust mit dem WebAssembly-Target, Node.js 22.12 oder neuer und npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

Wähle in der Entwicklung bei der Einrichtung die Demo-Quelle, um es ohne Abo auszuprobieren.

Die Desktop-Version nutzt Electron. Starte sie lokal oder baue die Pakete für macOS, Windows und Linux:

npm run desktop
npm run desktop:dist

Quelle einstecken. Play drücken.
