// 01 — funciones

Pensado para el mando,
cómodo en tu móvil.

Xtream & M3U

Catálogos leídos por bloques, servidores de respaldo, sincronización diferencial: solo se reescriben las filas modificadas.

Guía XMLTV

Cuadrícula canal × hora virtualizada, navegación día a día, gzip y zonas horarias gestionados. Los programas pasados se ven en replay.

Películas y series

Fichas enriquecidas con TMDB: reparto, colecciones, clasificación por edad, temporadas y episodios, reanudación y siguiente episodio.

Pausa en directo

Búfer local de 30 a 60 min: pausa, ±10 s y vuelta al directo en flujos HLS, con cambio automático a un flujo de respaldo.

Comandos de voz

«Pon el canal 5», «busca Dune», «retrocede 30 segundos». Interpretados en el dispositivo, en los 14 idiomas de la interfaz.

Configuración por código QR

Escanea el código de la TV con tu móvil: perfil, fuentes y ajustes llegan sin escribir una URL con el mando.

Replay gratuito

ARTE, france.tv y Okoo integrados, además de feeds RSS de YouTube. Los flujos oficiales van primero para los canales públicos.

Subtítulos y Trakt

SRT, WebVTT y búsqueda por hash en OpenSubtitles. Scrobbling de Trakt, lista de seguimiento y recomendaciones en el inicio.

Perfiles y almacén seguro

Varios perfiles con su propio idioma, avatar y límite de edad. Los tokens de servicios se quedan en el almacén seguro del dispositivo.

// 04 — instalar

Listo en dos minutos.

  1. Descarga Cyberstream-x.y.z.apk desde la última versión.
  2. Instálalo en tu móvil, o en la TV con adb:
adb -d install -r Cyberstream-1.0.1.apk

Android 7 (API 24) como mínimo, con un WebView compatible con WebAssembly. Después, la app busca sola las nuevas versiones en GitHub.

Rust estable con el target WebAssembly, Node.js 22.12 o posterior y npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

En desarrollo, elige la fuente de demostración durante la configuración para probarlo sin suscripción.

La versión de escritorio usa Electron. Ejecútala en local o genera los paquetes para macOS, Windows y Linux:

npm run desktop
npm run desktop:dist

Conecta tu fuente. Dale al play.
