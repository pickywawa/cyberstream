// 01 — funzioni

Pensato per il telecomando,
a suo agio sul telefono.

Xtream & M3U

Cataloghi letti a blocchi, server di riserva, sincronizzazione differenziale: vengono riscritte solo le righe modificate.

Guida XMLTV

Griglia canale × orario virtualizzata, navigazione giorno per giorno, gzip e fusi orari gestiti. I programmi passati si rivedono in replay.

Film e serie

Schede arricchite da TMDB: cast, collezioni, classificazioni per età, stagioni ed episodi, ripresa ed episodio successivo.

Pausa in diretta

Buffer locale da 30 a 60 min: pausa, ±10 s e ritorno alla diretta sui flussi HLS, con passaggio automatico a un flusso di riserva.

Comandi vocali

«Metti il canale 5», «cerca Dune», «torna indietro di 30 secondi». Interpretati sul dispositivo, nelle 14 lingue dell'interfaccia.

Configurazione con QR code

Inquadra il codice sulla TV con il telefono: profilo, sorgenti e impostazioni arrivano senza digitare un URL col telecomando.

Replay gratuito

ARTE, france.tv e Okoo integrati, più i feed RSS di YouTube. Per i canali pubblici i flussi ufficiali vengono prima.

Sottotitoli e Trakt

SRT, WebVTT e ricerca tramite hash OpenSubtitles. Scrobbling Trakt, watchlist e consigli nella home.

Profili e archivio sicuro

Più profili con lingua, avatar e limite di età propri. I token dei servizi restano nell'archivio sicuro del dispositivo.

// 04 — installa

Pronto in due minuti.

  1. Scarica Cyberstream-x.y.z.apk dall'ultima versione.
  2. Installalo sul telefono, o sulla TV con adb:
adb -d install -r Cyberstream-1.0.1.apk

Android 7 (API 24) come minimo, con un WebView che supporti WebAssembly. Poi l'app controlla da sola le nuove versioni su GitHub.

Rust stabile con il target WebAssembly, Node.js 22.12 o successivo e npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

In sviluppo, scegli la sorgente demo durante la configurazione per provarlo senza abbonamento.

La versione desktop usa Electron. Avviala in locale o crea i pacchetti per macOS, Windows e Linux:

npm run desktop
npm run desktop:dist

Collega la tua sorgente. Premi play.
