// 01 — funções

Feito para o controle remoto,
à vontade no celular.

Xtream & M3U

Catálogos lidos em blocos, servidores reserva, sincronização diferencial: só as linhas alteradas são reescritas.

Guia XMLTV

Grade canal × horário virtualizada, navegação dia a dia, gzip e fusos horários tratados. Os programas passados passam em replay.

Filmes e séries

Páginas enriquecidas pelo TMDB: elenco, coleções, classificação etária, temporadas e episódios, retomada e próximo episódio.

Pausa ao vivo

Buffer local de 30 a 60 min: pausa, ±10 s e voltar ao vivo nos streams HLS, com troca automática para um stream reserva.

Comandos de voz

“Coloca no canal 5”, “procura Dune”, “volta 30 segundos”. Entendidos no aparelho, nos 14 idiomas da interface.

Configuração por QR code

Escaneie o código da TV com o celular: perfil, fontes e configurações chegam sem digitar uma URL no controle.

Replay gratuito

ARTE, france.tv e Okoo integrados, mais feeds RSS do YouTube. Os streams oficiais vêm primeiro para os canais públicos.

Legendas e Trakt

SRT, WebVTT e busca por hash no OpenSubtitles. Scrobbling do Trakt, watchlist e recomendações na tela inicial.

Perfis e cofre

Vários perfis com idioma, avatar e limite de idade próprios. Os tokens dos serviços ficam no armazenamento seguro do aparelho.

// 04 — instalar

Pronto em dois minutos.

  1. Baixe Cyberstream-x.y.z.apk da versão mais recente.
  2. Instale no celular, ou na TV com adb:
adb -d install -r Cyberstream-1.0.1.apk

Android 7 (API 24) no mínimo, com um WebView compatível com WebAssembly. Depois, o app procura sozinho novas versões no GitHub.

Rust estável com o target WebAssembly, Node.js 22.12 ou posterior e npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

Em desenvolvimento, escolha a fonte de demonstração na configuração para testar sem assinatura.

A versão desktop usa Electron. Rode localmente ou gere os pacotes para macOS, Windows e Linux:

npm run desktop
npm run desktop:dist

Conecte a sua fonte. Aperte o play.

Cyberstream

O Cyberstream é um player. Ele não fornece, hospeda nem lista nenhum conteúdo: você usa as suas fontes. Código publicado sob a licença MIT.

Pôsteres, fotos e metadados: TMDB. Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB. Logos dos canais: banco de dados do iptv-org; marcas e artes pertencem aos seus donos. Vídeo do player: stream de teste Big Buck Bunny © Blender Foundation, CC BY 3.0.
