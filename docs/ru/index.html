// 01 — возможности

Создан для пульта,
удобен на телефоне.

Xtream & M3U

Каталоги читаются частями, резервные серверы, дифференциальная синхронизация: перезаписываются только изменённые строки.

Телегид XMLTV

Виртуализированная сетка «канал × время», навигация по дням, поддержка gzip и часовых поясов. Прошедшие передачи доступны в архиве.

Фильмы и сериалы

Страницы с данными TMDB: актёры, коллекции, возрастные рейтинги, сезоны и серии, продолжение просмотра и следующая серия.

Пауза эфира

Локальный буфер на 30–60 мин: пауза, ±10 с и возврат в эфир для потоков HLS, с автоматическим переключением на резервный поток.

Голосовые команды

«Включи пятый канал», «найди Дюну», «назад на 30 секунд». Распознаются на устройстве, на 14 языках интерфейса.

Настройка по QR-коду

Отсканируйте код на телевизоре телефоном: профиль, источники и настройки приходят без ввода URL пультом.

Бесплатный архив

Встроены ARTE, france.tv и Okoo, а также RSS-ленты YouTube. Для общественных каналов официальные потоки идут первыми.

Субтитры и Trakt

SRT, WebVTT и поиск по хешу в OpenSubtitles. Скробблинг Trakt, список просмотра и рекомендации на главной.

Профили и хранилище

Несколько профилей со своим языком, аватаром и возрастным ограничением. Токены сервисов хранятся в защищённом хранилище устройства.

// 04 — установка

Готово за две минуты.

  1. Скачайте Cyberstream-x.y.z.apk из последнего релиза.
  2. Установите его на телефон или на телевизор через adb:
adb -d install -r Cyberstream-1.0.1.apk

Минимум Android 7 (API 24) с WebView, поддерживающим WebAssembly. Дальше приложение само проверяет новые версии на GitHub.

Стабильный Rust с целью WebAssembly, Node.js 22.12 или новее и npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

В режиме разработки выберите демо-источник при настройке, чтобы попробовать без подписки.

Настольная версия работает на Electron. Запустите её локально или соберите пакеты для macOS, Windows и Linux:

npm run desktop
npm run desktop:dist

Подключите источник. Нажмите play.

Cyberstream

Cyberstream — это плеер. Он не предоставляет, не размещает и не каталогизирует никакой контент: вы используете свои источники. Код распространяется по лицензии MIT.

Постеры, фото и метаданные: TMDB. Этот продукт использует API TMDB, но не одобрен и не сертифицирован TMDB. Логотипы каналов: база данных iptv-org; товарные знаки и изображения принадлежат их владельцам. Видео в плеере: тестовый поток Big Buck Bunny © Blender Foundation, CC BY 3.0.
