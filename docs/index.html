// 01 — fonctions

Pensé pour la télécommande,
à l’aise sur le téléphone.

Xtream & M3U

Catalogues lus par blocs, serveurs de secours, synchronisation différentielle : seules les lignes modifiées sont réécrites.

Guide TV XMLTV

Grille chaînes × temps virtualisée, navigation jour par jour, gzip et fuseaux gérés. Les programmes passés se relisent en rattrapage.

Films & séries

Fiches enrichies par TMDB : casting, collections, restrictions d’âge, saisons et épisodes, reprise et épisode suivant.

Pause du direct

Tampon local de 30 à 60 min : pause, ±10 s et retour au direct sur les flux HLS, avec bascule auto vers un flux de secours.

Commande vocale

« Mets la chaîne 5 », « recherche Dune », « recule de 30 secondes ». Interprétation locale en français et en anglais.

Installation par QR code

Sur la TV, scanne le code avec ton téléphone : profil, sources et réglages arrivent sans taper une URL à la télécommande.

Replay gratuit

ARTE, france.tv et Okoo intégrés, plus les flux RSS YouTube. Flux officiels prioritaires pour les chaînes publiques.

Sous-titres & Trakt

SRT, WebVTT et recherche OpenSubtitles par empreinte. Scrobble Trakt, watchlist et recommandations sur l’accueil.

Profils & coffre

Plusieurs profils avec langue, avatar et limite d’âge. Les jetons des services restent dans le coffre de secrets de l’appareil.

// 04 — installer

Prêt en deux minutes.

  1. Télécharge Cyberstream-x.y.z.apk depuis la dernière publication.
  2. Installe-le sur le téléphone, ou sur la TV via adb :
adb -d install -r Cyberstream-1.0.1.apk

Android 7 (API 24) minimum, avec un WebView compatible WebAssembly. Ensuite, l’app vérifie elle-même les nouvelles versions sur GitHub.

Rust stable avec la cible WebAssembly, Node.js 22.12 ou ultérieur et npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

En développement, choisis la source de démonstration pendant la configuration pour tester sans abonnement.

L’hôte de bureau utilise Electron. Lancer en local ou produire les paquets macOS, Windows et Linux :

npm run desktop
npm run desktop:dist

Branche ta source. Appuie sur lecture.
