// 01 — fitur

Dibuat untuk remote,
nyaman di ponsel.

Xtream & M3U

Katalog dibaca per bagian, server cadangan, sinkronisasi diferensial: hanya baris yang berubah yang ditulis ulang.

Panduan XMLTV

Kisi saluran × waktu tervirtualisasi, navigasi per hari, gzip dan zona waktu ditangani. Acara yang sudah lewat bisa ditonton ulang.

Film & serial

Halaman yang diperkaya TMDB: pemeran, koleksi, rating usia, musim dan episode, lanjutkan menonton dan episode berikutnya.

Jeda siaran langsung

Buffer lokal 30 hingga 60 menit: jeda, ±10 dtk, dan kembali ke siaran langsung pada stream HLS, dengan peralihan otomatis ke stream cadangan.

Perintah suara

“Pindah ke saluran 5”, “cari Dune”, “mundur 30 detik”. Dipahami di perangkat, dalam 14 bahasa antarmuka.

Pengaturan lewat kode QR

Pindai kode di TV dengan ponselmu: profil, sumber, dan pengaturan masuk tanpa mengetik URL dengan remote.

Siaran ulang gratis

ARTE, france.tv, dan Okoo terpasang, ditambah feed RSS YouTube. Untuk saluran publik, stream resmi didahulukan.

Subtitel & Trakt

SRT, WebVTT, dan pencarian hash OpenSubtitles. Scrobbling Trakt, watchlist, dan rekomendasi di beranda.

Profil & brankas

Beberapa profil dengan bahasa, avatar, dan batas usia masing-masing. Token layanan tetap di penyimpanan aman perangkat.

// 04 — instal

Siap dalam dua menit.

  1. Unduh Cyberstream-x.y.z.apk dari rilis terbaru.
  2. Pasang di ponselmu, atau di TV dengan adb:
adb -d install -r Cyberstream-1.0.1.apk

Minimal Android 7 (API 24), dengan WebView yang mendukung WebAssembly. Setelah itu, aplikasi memeriksa versi baru di GitHub dengan sendirinya.

Rust stabil dengan target WebAssembly, Node.js 22.12 atau lebih baru, dan npm.

rustup target add wasm32-unknown-unknown
cargo install --locked wasm-bindgen-cli --version 0.2.108
npm ci
cargo test --locked && npm test
npm run dev -- --host 127.0.0.1

Saat pengembangan, pilih sumber demo ketika penyiapan untuk mencobanya tanpa langganan.

Versi desktop memakai Electron. Jalankan secara lokal atau buat paket macOS, Windows, dan Linux:

npm run desktop
npm run desktop:dist

Sambungkan sumbermu. Tekan play.

Cyberstream adalah pemutar. Aplikasi ini tidak menyediakan, menghosting, atau mendaftarkan konten apa pun: kamu memakai sumbermu sendiri. Kode dirilis di bawah lisensi MIT.
